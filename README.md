# Christening Invitation Website

A beautiful, premium, mobile-first Christening Invitation website designed primarily for Android smartphones.

## Image Assets Required

Place the following image files in the root directory:

### Baby
- `baby.png` - The baby's photo (will be displayed in a circular frame)

### Clouds
- `cloud1.png` - Decorative cloud element
- `cloud2.png` - Decorative cloud element  
- `cloud3.png` - Decorative cloud element

### Teddy Bears
- `teddy1.png` - Decorative teddy bear
- `teddy2.png` - Decorative teddy bear
- `teddy3.png` - Decorative teddy bear

## Features

- **Mobile-First Design**: Optimized for Android smartphones (360px - 430px width)
- **Beautiful Animations**: Scroll-triggered animations including fade in, slide up, scale in, and parallax effects
- **Elegant Typography**: Script font for baby's name, serif for headings, sans-serif for body text
- **Soft Color Palette**: Sky blue, baby blue, white, and subtle gold accents
- **Premium Feel**: Floating clouds, particles, and decorative elements create a magical atmosphere
- **Responsive**: Adapts gracefully to tablets and desktop screens

## Sections

1. **Hero** - Baby portrait with name and invitation title
2. **Invitation Message** - Warm welcome message
3. **Event Details** - Date, time, location, and reception information
4. **Parents** - Proud parents section
5. **Godparents** - Godparents section
6. **Gallery** - Photo gallery (placeholder images)
7. **Closing** - RSVP information and contact details

## Customization

Edit `index.html` to customize:
- Baby's name (line 56)
- Event details (lines 78-103)
- Parents' names (lines 113-120)
- Godparents' names (lines 130-137)
- RSVP date and contact info (lines 157-160)

## Technologies Used

- Pure HTML5
- Pure CSS3 (no frameworks)
- Vanilla JavaScript (Intersection Observer API for scroll animations)
- Google Fonts (Great Vibes, Cormorant Garamond, Inter)

## Browser Support

- Modern mobile browsers (Chrome, Firefox, Safari)
- Desktop browsers (Chrome, Firefox, Safari, Edge)
- Reduced motion support for accessibility
